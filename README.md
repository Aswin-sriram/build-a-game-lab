# Build-a-Game Lab

Students pick one of 10 games, type the 5 key parts of its code by hand, press Run to play the game they built, and share it with a link.

Live site: https://aswin-sriram.github.io/build-a-game-lab/

- `index.html` – the lab (typing editor, simulator, share links)
- `games.js` – the 10 games, each split into parts students type and parts written for them
